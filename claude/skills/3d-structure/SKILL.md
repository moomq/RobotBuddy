# 3D Structure Skill — RobotBuddy

## Role

RobotBuddy 3D 结构与外壳设计专家，负责机器人外壳建模、PCB 布局约束、重心分析和组装指南。

## Domain

3D 打印外壳设计、PLA/树脂材料特性、PCB 安装约束、电机/电池/传感器布局、重心与稳定性、3D 建模工具（Fusion 360 / OpenSCAD）。

## Goal

设计美观、实用、可制造的 RobotBuddy 物理外壳，确保所有电子组件合理安装、重心稳定、组装便捷。

## Inputs

- 外观设计需求（PRD §外观设计）
- PCB 尺寸和组件布局
- 电机/电池/屏幕/传感器物理尺寸
- 3D 打印机规格（FDM/SLA）

## Outputs

- `docs/design/3d-model-notes.md` — 3D 模型设计说明
- `docs/design/appearance-spec.md` — 外观规格说明
- `docs/hardware/assembly-guide.md` — 组装指南
- `models/` — 3D 模型文件（STL/STEP）
- `docs/hardware/pinout.md` — 引脚分配表（含物理位置）

## Center of Gravity Analysis

```c
// 重心分析（确保桌面稳定性）
//
// 组件重量估算:
// ESP32-S3 模组:     ~5g
// PCB (含元件):       ~15g
// 18650 电池:         ~45g  ← 最重组件
// ST7789 屏幕:       ~8g
// N20 电机 ×2:       ~20g
// 扬声器:            ~10g
// DRV8833 板:        ~3g
// 外壳 (PLA):        ~40g
// 螺丝/线材:          ~5g
// ──────────────────────
// 总计:              ~151g

// 重心设计原则:
// 1. 电池放最低位置 → 降低重心
// 2. 电机轴线在重心以下 → 稳定
// 3. 屏幕不过高 → 避免头重脚轻
// 4. 轮距足够宽 → 防止侧翻
// 5. 重心投影在轮距范围内 → 静止时不倾倒

// 稳定性指标:
// 倾倒角 ≥ 15° (水平推力测试)
// 轮距 / 重心高度 ≥ 1.0
```

//    ├── 扬声器格栅内侧加防尘网
//    ├── 屏幕窗口做台阶（保护屏幕表面）
//    └── 底部加防滑脚垫（4× Φ10mm 硅胶垫）
//
// 5. 外观
//    ├── 主色: 奶油白 (RAL 9001 / #FDF4E3)
//    ├── 屏幕框: 深灰 (RAL 7016 / #383E42)
//    ├── 表面: 亮面处理 (打磨 + 清漆)

## 3D Printing Guide

```c
// 打印参数建议
//
// FDM 打印 (推荐 PLA/PLA+):
// ├── 层高:        0.2mm (外表面) / 0.3mm (内部结构)
// ├── 壁厚:        2mm (3 层 @ 0.4mm 喷嘴)
// ├── 填充:        20% 网格 (外壳) / 50% (螺丝柱)
// ├── 支撑:        上壳内部需要 (屏幕窗口朝上打印)
// ├── 打印温度:    200-210°C (PLA)
// ├── 热床温度:    60°C
// └── 后处理:      打磨层纹 → 补土 → 喷漆 (奶油白)
//
// SLA 树脂打印 (更精细):
// ├── 精度:        0.05mm
// ├── 适合:        屏幕窗口、卡扣细节
// ├── 树脂:        标准灰色树脂 + 喷漆
// └── 缺点:        成本高、尺寸受限
//
// 打印方向建议:
// ├── 上壳:    屏幕窗口朝上 → 支撑在内侧
// ├── 中框:    竖直打印 → 最少支撑
// └── 底盖:    平面朝下 → 无需支撑
```

## Rules

1. **螺丝可拆** — 外壳必须可拆卸，方便维修和固件烧录
2. **USB-C 可达** — 充电和烧录口必须方便插拔，不需拆壳
3. **重心稳定** — 重心投影在轮距范围内，倾倒角 ≥ 15°
4. **传感器窗口** — 红外/TOF 传感器必须有对应开窗，不被遮挡
5. **麦克风位置** — 麦克风远离扬声器和电机，减少噪音干扰
6. **散热考虑** — ESP32 和 DRV8833 区域有通风路径
7. **线缆管理** — 内部排线有固定槽/扎带位，不干扰运动部件
8. **屏幕保护** — 屏幕窗口做台阶或凹陷，屏幕表面不高于外壳表面

## Checklist

- [ ] 所有组件有物理安装位置和固定方式
- [ ] 外壳可完全拆卸（维修友好）
- [ ] 重心计算通过（轮距/重心高度 ≥ 1.0）
- [ ] 屏幕窗口对齐（显示区域无遮挡）
- [ ] 扬声器孔位对齐（声音无遮挡）
- [ ] 麦克风孔位远离扬声器（减少回声）
- [ ] 传感器窗口对齐（IR/TOF 发射接收无遮挡）
- [ ] USB-C 口方便插拔
- [ ] 3D 打印件尺寸精度 ±0.3mm
- [ ] 组装后外观与 PRD 外观设计一致
- [ ] 所有螺丝孔位对齐，无错位
