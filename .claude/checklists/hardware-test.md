## 1. 硬件连接验证

- [ ] 原理图与实际连接一致
- [ ] 电源电压正确 (3.3V / 5V)
- [ ] 信号线连接正确 (SDA/SCL/MOSI/MISO/SCK/CS 等)
- [ ] 上拉/下拉电阻已安装
- [ ] 去耦电容已安装 (100nF + 10μF)
- [ ] 无短路（万用表蜂鸣档确认 VCC-GND 不通）
- [ ] PCB 走线长度合理（高速信号 < 10cm）

---

## 2. 通信验证

### 2.1 I2C 设备
- [ ] `i2c-tools` 扫描到正确地址 (0x__ )
- [ ] WHO_AM_I / CHIP_ID 寄存器读取正确 (0x__)
- [ ] 写入寄存器后读回验证一致
- [ ] I2C 速率可达目标频率 (____kHz)
- [ ] 多次读取数据稳定（连续 100 次无错误）

### 2.2 SPI 设备
- [ ] SPI 时钟信号正常（示波器确认）
- [ ] CS 片选信号时序正确
- [ ] 数据读写正确（读寄存器验证）
- [ ] SPI 速率可达目标频率 (____MHz)
- [ ] DMA 传输正常（大块数据传输无错误）

### 2.3 I2S 设备
- [ ] I2S 时钟信号正常 (BCLK/WS)
- [ ] 录音：麦克风数据可读且非零
- [ ] 播放：扬声器输出正常音频
- [ ] 采样率正确 (16kHz / 其他)
- [ ] DMA 缓冲区无 underrun/overrun

### 2.4 PWM 设备
- [ ] PWM 频率正确 (____Hz)
- [ ] PWM 占空比可调 (0-100%)
- [ ] 电机转向正确（正转/反转）
- [ ] 电机转速与占空比线性关系

### 2.5 ADC 设备
- [ ] ADC 读取值范围正确
- [ ] 多次采样均值稳定
- [ ] 分压系数校准完成
