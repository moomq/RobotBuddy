## 1. 物理安全

### 1.1 机械安全

- [ ] 机器人无锐利边缘和尖角
- [ ] 双轮有防夹设计（底盘与轮子间隙 > 5mm）
- [ ] 桌面防跌落检测正常（ITR20001 至少 2 个）
- [ ] 防跌落响应时间 ≤ 100ms
- [ ] 电机堵转检测和保护正常
- [ ] 最大移动速度 ≤ 0.3 m/s
- [ ] 紧急停止功能正常（软件急停指令）

### 1.2 电气安全

- [ ] 电池过充保护正常 (TP4056 CC/CV)
- [ ] 电池过放保护正常 (3.0V 截止)
- [ ] 电池短路保护正常
- [ ] USB 充电电流限制 (≤ 1A)
- [ ] 升压电路输出电压稳定 (5V ± 0.2V)
- [ ] 温度监测正常（电池温度 ≤ 60°C）
- [ ] 充电时机器人移动功能禁用

### 1.3 热安全

- [ ] ESP32-S3 满负荷温度 ≤ 65°C（环境 25°C）
- [ ] 电机驱动芯片温度 ≤ 70°C
- [ ] 电池充电温度 ≤ 45°C
- [ ] 长时间运行 (4h) 无过热告警

---

## 2. 网络安全

### 2.1 WiFi 安全

- [ ] WiFi 密码 AES-256 加密存储在 NVS
- [ ] WiFi 凭证不在日志中明文输出
- [ ] SmartConfig 配网过程使用加密信道
- [ ] 出厂重置时清除所有 WiFi 凭证
- [ ] 支持 WPA3（如路由器支持）

### 2.2 通信安全

- [ ] 所有云端通信使用 TLS 1.2+
- [ ] OTA 固件使用 RSA-2048 签名验证
- [ ] MQTT 消息使用 TLS 加密
- [ ] WebSocket 使用 WSS (加密)
- [ ] API Token 定期刷新 (≤ 24h)
- [ ] 设备证书/密钥安全存储在 NVS 加密分区

### 2.3 数据安全

- [ ] 麦克风数据仅在唤醒后上传
- [ ] 麦克风静默期间硬件级断电（非静音）
- [ ] 本地存储的对话历史加密
- [ ] 用户隐私数据不在日志中明文记录
- [ ] 语音数据上传前经过匿名化处理
- [ ] 设备恢复出厂设置时清除所有用户数据

---

## 3. 固件安全

### 3.1 启动安全

- [ ] Secure Boot V2 已启用（生产环境）
- [ ] Flash Encryption 已启用（生产环境）
- [ ] eFuse 配置正确且不可逆
- [ ] JTAG 调试口在生产版本中禁用
- [ ] UART 日志在生产版本中禁用或限制级别

### 3.2 运行时安全

- [ ] 看门狗定时器已启用（Task WDT + IWDT）
- [ ] 栈溢出检测已启用
- [ ] 堆内存越界检测已启用 (heap poisoning)
- [ ] 不安全函数已禁用 (sprintf → snprintf)
- [ ] 所有 malloc 返回值已检查
- [ ] 所有 esp_err_t 返回值已检查
- [ ] ISR 函数均标记 IRAM_ATTR
- [ ] ISR 中无阻塞操作

### 3.3 OTA 安全

- [ ] OTA 固件签名验证启用
- [ ] OTA 下载使用 HTTPS
- [ ] OTA 服务器 URL 使用 HTTPS
- [ ] OTA 失败自动回滚机制正常
- [ ] factory 分区不可 OTA 覆盖
- [ ] OTA 过程中断电后可恢复或回滚

---

## 4. 功能安全

### 4.1 紧急行为

- [ ] 低电量 (<10%) 自动停止移动
- [ ] 低电量 (<5%) 进入深度睡眠
- [ ] 防跌落传感器触发立即停止电机
- [ ] 障碍物近距离 (<3cm) 紧急制动
- [ ] IMU 检测到跌落立即停止所有运动
- [ ] 软件急停指令可立即停止所有电机
- [ ] 看门狗超时重启后进入安全模式

### 4.2 降级行为

- [ ] WiFi 断开 → 本地模式（命令词 + 预置表情）
- [ ] 云端 AI 不可用 → 本地命令词模式
- [ ] 电池低电量 → 限制移动和显示
- [ ] 传感器故障 → 安全停止运动
- [ ] 内存不足 → 释放非关键资源

---

## 5. 隐私安全

- [ ] 麦克风仅在唤醒后激活
- [ ] 摄像头（如有）仅在用户授权后启用
- [ ] 语音数据不在本地持久存储
- [ ] 对话历史默认不存储
- [ ] WiFi 密码安全存储和传输
- [ ] 恢复出厂设置清除所有个人数据
- [ ] 遵守当地隐私法规 (GDPR/个人信息保护法)

---

## 6. 合规性

- [ ] 电磁兼容 (EMC) 测试通过（如适用）
- [ ] 电池安全认证 (UN38.3 / IEC 62133)
- [ ] 充电器认证 (CCC/CE/FCC)
- [ ] 无线电型号核准 (SRRC/FCC)
- [ ] 产品标签和警告语完整
