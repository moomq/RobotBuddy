## 1. 编译检查

- [ ] `idf.py build` 零错误零警告
- [ ] `-Wall -Werror` 编译通过
- [ ] Flash 使用量 < 分配大小的 80%
- [ ] DRAM 使用量 < 512KB 的 80%
- [ ] PSRAM 使用量 < 8MB 的 75%
- [ ] 所有 Kconfig 选项确认正确
- [ ] Release 模式编译 (非 Debug)
- [ ] 版本号已更新 (`app_version.h`)

---

## 2. 测试检查

- [ ] L1 单元测试全部通过

- [ ] L3 集成测试全部通过
- [ ] L4 压力测试通过（≥24h 无异常）
- [ ] 行覆盖率 ≥ 80%
- [ ] 分支覆盖率 ≥ 70%
- [ ] 无已知 P0/P1 Bug 未修复

## 3. 代码质量检查

- [ ] 错误处理路径已覆盖
