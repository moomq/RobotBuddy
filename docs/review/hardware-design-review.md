# 硬件设计审查报告 — RobotBuddy V1.0

> 对照 embedded-coding.md 和 hardware-driver skill 检查引脚定义、驱动接口一致性、BOM 与原理图匹配、电源设计合理性。

**版本:** 1.0.0
**审查日期:** 2026-07-18
**审查范围:** 硬件设计方案-电路原理图

---

## 审查结果

### 🔴 Critical (必须修复 — 阻塞 PCB 制板)

1. **I2C 总线句柄泄漏** — `bsp_board.c:96-97`
   - **问题:** `i2c_new_master_bus()` 返回的 `bus_handle` 为局部变量，函数返回后丢失。`bsp_board_deinit()` 注释标注"应该存储全局或传递给驱动"但未实现。
   - **影响:** I2C 总线无法正确释放，导致内存泄漏和热重启问题。
   - **建议:** 将 `bus_handle` 存储为静态全局变量或通过 BSP 上下文结构体传递给各驱动。

2. **I2S 初始化死代码** — `bsp_board.c:129-192`
   - **问题:** `bsp_init_i2s()` 函数完整实现但未被 `bsp_board_init()` 调用。注释说"I2S 由 audio_manager 管理"，但函数仍保留。
   - **影响:** 维护困惑 — 新开发者可能误调用；代码体积增加（虽然链接器可能优化）。
   - **建议:** 删除 `bsp_init_i2s()` 或将其移到 `audio_manager.c` 中（如果需要作为参考实现）。

### 🟡 Warning (强烈建议修复)

3. **5V 电源轨裕量不足** — 电源设计
   - **问题:** MT3608 最大输出 2A，但电机峰值（2×1.2A=2.4A）+ 功放峰值（0.9A）= 3.3A，远超 MT3608 能力。
   - **影响:** 电机堵转或功放大音量时可能触发升压模块过流保护，导致 5V 轨掉电，ESP32 重启。
   - **建议:** (a) 选择更大电流的升压模块（如 SX1308 3A 或 TPS63020 4A）；(b) DRV8833 设置限流 ~800mA；(c) 行为系统确保电机和功放不同时满功率运行。

4. **电池续航可能不满足 PRD** — 电源设计
   - **问题:** PRD 要求活跃续航 ≥4h，当前估算约 1.7h（全功率）到 3.25h（仅对话）。
   - **影响:** 用户使用体验差，频繁充电。
   - **建议:** (a) 选用 3400mAh 电池；(b) 实现动态功耗管理（WiFi 省电模式）；(c) 屏幕 PWM 调光；(d) PRD 续航指标可能需要调整为"对话模式 ≥3h"。

5. **I2C 双重上拉** — `bsp_board.c:93`
   - **问题:** 外部 4.7kΩ 上拉 + ESP32 内部上拉同时启用（`enable_internal_pullup = true`）。
   - **影响:** 合并电阻约 4.25kΩ，功能正常但冗余。极端情况下可能导致信号完整性问题。
   - **建议:** 将 `enable_internal_pullup` 改为 `false`，仅依赖外部上拉。

6. **INMP441 L/R 引脚未在原理图中明确标注** — 音频子系统
   - **问题:** INMP441 的 L/R 引脚需要接地才能选择左声道，但原理图说明中仅文字描述，未在连接图中标注。
   - **影响:** 焊接时可能遗漏此连接，导致麦克风无数据输出。
   - **建议:** 在原理图连接图中增加 INMP441 L/R → GND 的明确连接。

### 🔵 Suggestion (可选的优化建议)

7. **缺少电机堵转检测** — 电机子系统
   - **问题:** DRV8833 的 nFAULT 引脚未连接，无法检测过流/过温故障。
   - **建议:** 预留 GPIO 连接 DRV8833 nFAULT 引脚（如 GPIO2），或使用 ADC 检测电机电流。

8. **缺少电源指示 LED** — 电源子系统
   - **问题:** 无电源状态指示灯（充电中/充满/低电量）。
   - **建议:** 增加一个 RGB LED 或两个单色 LED 用于电源状态指示。

9. **缺少 MicroSD 卡槽** — 扩展性
   - **问题:** 无本地存储扩展，OTA 固件和音频缓存只能依赖 Flash。
   - **建议:** V2.0 考虑增加 MicroSD 卡槽用于日志、音频文件、表情资源。

10. **TP4056 充电电流固定 1A** — 充电设计
    - **问题:** PROG 电阻 1.2kΩ 对应 1A 充电电流，Type-C 5V/1A 电源刚好匹配但无裕量。
    - **建议:** 使用 2kΩ 电阻（500mA 充电）以增加兼容性，或使用可编程充电 IC。

11. **音频子系统和电机子系统信号隔离** — PCB 设计
    - **问题:** I2S 引脚 (GPIO4-7) 和 PWM 引脚 (GPIO10-13) 在引脚排列上较近。
    - **建议:** PCB 布局时确保 I2S 走线和 PWM 走线物理隔离，减少电机噪声耦合到音频。
