# 硬件设计方案-电路原理图 — 功能需求分析

> 将产品 PRD 中的硬件需求拆解为可执行的电路原理图设计需求。

**版本:** 1.0.0
**最后更新:** 2026-07-18
**适用范围:** RobotBuddy V1.0 (MVP)

---

## 1. 功能描述

### 1.1 一句话定义

设计 RobotBuddy V1.0 完整电路原理图，覆盖主控、电源、显示、音频、电机、传感器六大子系统，确保所有硬件模块的电气连接正确、可靠、可生产。

### 1.2 触发条件

- 新产品开发：从 PRD 到原理图的设计阶段
- PCB 制板前：原理图是 PCB 布局的前置输入
- 驱动开发前：固件 BSP 层（bsp_pinmap.h）需与原理图完全一致

### 1.3 期望结果

- 一份完整的、可指导 PCB Layout 的电路原理图文档
- 完整的 ESP32-S3 引脚分配表（与 bsp_pinmap.h 一致）
- 所有子系统的电气参数和接口定义
- BOM（物料清单）与原理图完全匹配

## 2. 子系统需求

### 2.1 主控子系统

| 需求项 | 规格 | 说明 |
|--------|------|------|
| 主控芯片 | ESP32-S3-WROOM-1-N16R8 | 16MB Flash, 8MB PSRAM, OTA 双分区 |
| 供电电压 | 3.3V (典型值), 容差 ±5% | ESP32-S3 供电要求 |
| 最大电流 | 500mA (WiFi 激活时) | 需考虑瞬态峰值 |
| USB 接口 | Type-C (USB 2.0) | 供电 + 烧录 + JTAG 调试 |
| 启动配置 | GPIO0=HIGH → Flash 启动 | 启动模式选择 |
| 复位 | EN 引脚低电平复位 | 需去抖电容 |
| Strapping 引脚 | GPIO0, GPIO3, GPIO45, GPIO46 | 上电时需稳定电平 |

### 2.2 电源子系统

| 需求项 | 规格 | 说明 |
|--------|------|------|
| 电池 | 18650 锂电池 3.7V 2600mAh | 单节，内置保护板 |
| 充电 IC | TP4056, Type-C 接口, 1A 充电 | CC/CV 充电曲线 |
| 升压 IC | MT3608, 3.7V → 5V, ≥2A | 供 ESP32 + 屏幕 + 电机 |
| LDO | 3.3V LDO (AMS1117-3.3 或等效) | 5V → 3.3V, ≥1A |
| 电量检测 | 电阻分压 + ADC (2:1) | GPIO1 / ADC1_CH0 |
| 充电状态 | CHRG / STDBY 引脚 | GPIO18 / GPIO21 |
| 电源指示 | LED 指示 (充电中/充满/低电量) | 可选 |
| 过流保护 | 自恢复保险丝 | 5V 和 3.3V 各一路 |

**异常处理：**
- 电池过放 (< 3.0V) → ESP32 进入 Deep Sleep，仅保留 RTC
- 电池过压 (> 4.2V) → TP4056 内置保护
- 充电中开机 → 正常工作 + 充电并行
- 电池反接 → 保护板防止反接

### 2.3 显示子系统

| 需求项 | 规格 | 说明 |
|--------|------|------|
| 屏幕 | ST7789 IPS LCD, 240×240 | 1.69" 或 2.0" |
| 接口 | SPI (Mode 0), 40MHz | SPI3_HOST (VSPI) |
| 引脚 | SCLK, MOSI, CS, DC, RST, BL | 6 线 SPI |
| 背光 | GPIO 控制 BL 引脚 | PWM 可调亮度（可选） |
| 帧缓冲 | 240×240×2 = 115,200 bytes | 分配在 PSRAM |
| 供电 | 3.3V 逻辑, 背光可能需 5V | 需确认背光电压 |

**异常处理：**
- SPI 通信超时 → 重试 3 次，仍失败则报错
- 背光故障 → 降级运行（无背光）

### 2.4 音频子系统

| 需求项 | 规格 | 说明 |
|--------|------|------|
| 麦克风 | INMP441 MEMS, I2S 数字输出 | 16kHz, 16bit, 单声道 |
| 功放 | MAX98357A, I2S 输入, 3W D 类 | 无需外部滤波 |
| 扬声器 | 3W 全频, Φ28mm 或 Φ36mm | 8Ω 阻抗 |
| 采样率 | 16kHz | 语音识别标准 |
| 位深 | 16bit | — |
| I2S 配置 | BCLK, WS, DIN(INMP441), DOUT(MAX98357A) | 全双工 |
| INMP441 L/R 选择 | L/R 引脚接地 → 左声道 | — |

**异常处理：**
- 麦克风无信号 → 检测静音超时，提示用户
- 功放过热 → 降音量或静音保护
- I2S 时序错误 → 重新初始化 I2S

### 2.5 电机子系统

| 需求项 | 规格 | 说明 |
|--------|------|------|
| 电机驱动 | DRV8833 双路 H 桥 | 2 × N20 电机 |
| 电机 | N20 减速电机, 6V, ~200RPM | 每路 ≤ 1.2A 峰值 |
| PWM 频率 | 10kHz | 可听噪声以上 |
| PWM 分辨率 | 8-bit (0-255) | LEDC 定时器 |
| 控制引脚 | AIN1, AIN2, BIN1, BIN2 | 4 × GPIO + PWM |
| 休眠控制 | nSLEEP 引脚 | 低电平休眠（可选） |
| 故障检测 | FAULT 引脚 (可选) | 过流/过温保护 |
| 供电 | 5V (来自升压) | 电机需稳定 5V |
| 电机去耦 | 100μF 电解 + 100nF 陶瓷 | 电机电源去耦 |

**异常处理：**
- 电机堵转 → DRV8833 FAULT 检测，限流保护
- 过热 → 降低 PWM 占空比
- 低电量 (< 3.3V) → 停止电机，仅保留显示和通信

### 2.6 传感器子系统

| 传感器 | 接口 | 引脚数 | 用途 | 说明 |
|--------|------|--------|------|------|
| MPU6050 | I2C (0x68) | 2 (SDA/SCL) | 姿态检测、跌落检测 | 6 轴, 400kHz |
| TCRT5000 ×2 | GPIO 数字输入 | 2 | 前方避障 | 数字输出，低电平触发 |
| ITR20001 ×2 | GPIO 数字输入 | 2 | 桌面边缘检测 | 数字输出，低电平触发 |
| 电池 ADC | ADC1_CH0 | 1 | 电压检测 | 2:1 电阻分压 |
| TP4056 状态 | GPIO 输入 | 2 | 充电状态 | CHRG/STDBY |

**异常处理：**
- I2C 通信失败 → 3 次重试，仍失败则禁用 IMU
- 红外传感器持续触发 → 避障逻辑优先
- ADC 读数异常 → 中值滤波 + 异常值丢弃

### 3.2 引脚冲突检查

- ✅ 无 GPIO 复用冲突
- ✅ Strapping 引脚有明确上拉/下拉
- ✅ USB D+/D- 专用引脚（GPIO19/20）
- ✅ UART0 保留（GPIO43/44）
- ⚠️ GPIO0 (BOOT) 需上拉电阻 (10kΩ)
- ⚠️ GPIO45 需接 3.3V (VDD_SPI 配置)

## 4. 电源预算

### 4.1 电流需求估算

| 模块 | 典型电流 | 峰值电流 | 供电 |
|------|---------|---------|------|
| ESP32-S3 (WiFi 激活) | 200mA | 500mA | 3.3V |
| ST7789 LCD (背光 ON) | 30mA | 50mA | 3.3V |
| INMP441 麦克风 | 5mA | 5mA | 3.3V |
| MAX98357A 功放 (3W) | 600mA | 900mA | 5V |
| DRV8833 + 2×N20 (运行) | 400mA | 1200mA | 5V |
| MPU6050 IMU | 4mA | 4mA | 3.3V |
| TCRT5000 ×2 | 20mA | 20mA | 3.3V |
| ITR20001 ×2 | 10mA | 10mA | 3.3V |
| **合计 (3.3V)** | **~270mA** | **~570mA** | — |
| **合计 (5V)** | **~1000mA** | **~2100mA** | — |

### 4.2 电源路径

```
18650 Battery (3.7V)
    │
    ├── TP4056 Charge (Type-C 5V → Battery)
    │
    ├── MT3608 Boost (3.7V → 5V)
    │   ├── DRV8833 Motor Driver (5V)
    │   ├── MAX98357A Amp (5V)
    │   └── AMS1117-3.3 (5V → 3.3V)
    │       ├── ESP32-S3 (3.3V)
    │       ├── ST7789 LCD Logic (3.3V)
    │       ├── INMP441 Mic (3.3V)
    │       ├── MPU6050 IMU (3.3V)
    │       └── IR Sensors (3.3V)
    │
    └── Battery ADC (分压 → GPIO1)
```

### 4.3 电池续航估算

| 场景 | 电流 | 续航 (2600mAh) |
|------|------|----------------|
| 活跃 (WiFi+语音+显示+移动) | ~1500mA | ~1.7h |
| 对话 (WiFi+语音+显示) | ~800mA | ~3.25h |
| 待机 (显示+低功耗) | ~100mA | ~26h |
| Deep Sleep | ~10mA | ~260h |

### 6.1 受影响的任务

| 任务 | 影响 | 说明 |
|------|------|------|
| display_refresh | 低 | 引脚分配已在 bsp_pinmap.h 中定义 |

| motion_ctrl | 低 | PWM 引脚已分配 |

| cloud_comm | 无 | WiFi 内置，无额外引脚 |

### 6.2 内存影响

- SPI 帧缓冲: 240×240×2 = 115,200 bytes (PSRAM)
- I2S DMA 缓冲: 4096 × 2 = 8,192 bytes (PSRAM)
- 预计 PSRAM 占用: ~150KB / 8MB (充足)

## 7. 异常处理

### 7.1 电源异常

| 异常 | 检测方式 | 处理 |
|------|---------|------|
| 电池过放 (< 3.0V) | ADC 读数 | Deep Sleep，关闭所有外设 |
| 电池过充 | TP4056 内置 | 自动停止充电 |
| 5V 升压失败 | 无 5V 输出 | 降级运行（无电机/音频） |
| 3.3V LDO 压降 | 电压监测 | 降低 WiFi 功耗，关闭背光 |

### 7.2 通信异常

| 异常 | 检测方式 | 处理 |
|------|---------|------|
| I2C 总线挂死 | 超时/SCL 被 | I2C 总线恢复（9 个 SCL 脉冲） |
| SPI 通信超时 | 返回值检查 | 重试 3 次，报错 |
| I2S 数据错误 | DMA 溢出 | 重启 I2S 通道 |

### 7.3 硬件故障

| 异常 | 检测方式 | 处理 |
|------|---------|------|
| 屏幕无响应 | SPI 初始化失败 | 日志报错，关闭显示任务 |
| 麦克风无信号 | 静音检测超时 | 日志报错，禁用语音功能 |
| IMU 无响应 | I2C WHO_AM_I 失败 | 3 次重试，禁用 IMU |
| 电机堵转 | DRV8833 FAULT | 停止电机，日志报错 |

## 8. 验收条件

### 8.1 原理图验收

- [ ] 所有子系统的电路原理图绘制完成
- [ ] ESP32-S3 引脚分配与 bsp_pinmap.h 完全一致
- [ ] 所有元器件有完整的型号、封装、值标注
- [ ] 电源路径清晰：电池 → 升压 → LDO → 各模块
- [ ] 去耦电容计算正确（每 IC 旁 100nF + 电源入口 100μF）
- [ ] 所有网络标号（Net Label）清晰无歧义
- [ ] 无悬空引脚（所有输入有明确上下拉）
- [ ] 所有 Strapping 引脚有正确的上下拉电阻

### 8.2 电气验收

- [ ] ESP32-S3 供电 3.3V ±5% 在所有负载条件下
- [ ] 5V 升压电路输出 ≥ 2A 峰值电流
- [ ] 3.3V LDO 输出 ≥ 1A 峰值电流
- [ ] I2C 上拉电阻 4.7kΩ (400kHz 模式)
- [ ] SPI 时钟 ≤ 40MHz
- [ ] 所有数字输入有上拉或下拉电阻
- [ ] 电机驱动有续流二极管保护

### 8.3 BOM 验收

- [ ] BOM 与原理图元器件一一对应
- [ ] 所有元器件有供应商和采购链接
- [ ] 替代件标注清晰
- [ ] 估算总成本 ≤ ¥200 (不含 PCB 和外壳)
