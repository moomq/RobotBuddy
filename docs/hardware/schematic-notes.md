## 1. 主控子系统 — ESP32-S3-WROOM-1-N16R8

### 1.1 最小系统电路

```
                    3.3V
                     │
                    ┌┴┐ 10kΩ
                    └┬┘
                     │
        ┌────────┐──┘
        │ GPIO0  │──── BOOT 按钮 (可选: 对地接按钮)
        │ (BOOT) │
        │        │
        │ GPIO45 │──── 3.3V (VDD_SPI = 外部 3.3V)
        │        │
        │ GPIO46 │──── GND (禁止 ROM 消息打印)
        │        │
        │ EN     │───── 复位电路
        │        │     10kΩ 上拉 + 100nF 到地
        │        │     ┌──── 3.3V
        │        │     │
        │        │    ┌┴┐ 10kΩ
        │        │    └┬┘
        │ EN     │────┤
        │        │    ┌┴┐ 100nF
        │        │    └┬┘
        │        │     │
        │        │    GND
        │        │
        │ GND    │──── GND
        │ 3V3    │──── 3.3V (10μF + 100nF × 3 去耦)
        │ VDD    │──── 3.3V (模拟供电, 10μF + 100nF 去耦)
        │        │
        │ GPIO19 │──── USB D+ (Type-C)
        │ GPIO20 │──── USB D- (Type-C)
        │        │
        │ GPIO43 │──── UART0 TX (控制台)
        │ GPIO44 │──── UART0 RX (控制台)
        │        │
        └────────┘
```

### 1.2 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 供电电压 | 3.0V ~ 3.6V (典型 3.3V) | VDD 供电 |
| 工作温度 | -40°C ~ 85°C | 工业级 |
| Flash | 16MB (128Mbit) | OTA 双分区 |
| PSRAM | 8MB (OTCA 模式) | 大数据缓冲 |
| WiFi | 802.11 b/g/n, 2.4GHz | 内置天线 |
| 最大功耗 | ~500mA (WiFi 激活) | 瞬态峰值 |

### 1.3 去耦电容

| 位置 | 电容 | 说明 |
|------|------|------|
| VDD (3V3) | 10μF 陶瓷 + 100nF × 3 | 靠近引脚，分散放置 |
| VDDA (模拟) | 10μF + 100nF | 靠近引脚 |
| EN | 100nF | 复位去抖 |

### 2.4 电池电压检测电路

```
VBAT+ (3.0~4.2V)
     │
    ┌┴┐ R1 = 100kΩ
    └┬┘
     │──── GPIO1 (ADC1_CH0)
     │
    ┌┴┐ R2 = 100kΩ
    └┬┘
     │
    GND

ADC 值 = VBAT × R2 / (R1 + R2) = VBAT × 0.5
VBAT = ADC_VALUE × 2 × 3.3 / 4095

示例:
  VBAT = 3.7V → ADC = VBAT/2/3.3×4095 ≈ 2291
  VBAT = 4.2V → ADC ≈ 2606
  VBAT = 3.0V → ADC ≈ 1861
```

### 3.3 初始化时序

```
1. RST 拉低 10ms
2. RST 拉高
3. 等待 120ms
4. 发送 SWRESET (0x01) 软复位命令
5. 等待 120ms
6. 发送配置命令序列:
   ├── SLPOUT (0x11)  → 退出睡眠
   ├── 等待 120ms
   ├── COLMOD (0x3A) → 16-bit (0x05)
   ├── MADCTL (0x36) → 旋转/镜像
   ├── CASET (0x2A)  → 列地址 0~239
   ├── RASET (0x2B)  → 行地址 0~239
   ├── INVON (0x21)   → 反色 (取决于屏幕)
   └── DISPON (0x29) → 开显示
```

### 4.3 I2S 时序

```
         ┌───┐   ┌───┐   ┌───┐   ┌───┐
BCLK  ───┘   └───┘   └───┘   └───┘   └───
         ┌───────────────┐───────────────
WS    ───┘               └───────────────
         ─────────────────┌──────────────
DIN   ──← D15 ... D0 ──→─┌──────────────
         (左声道, 16bit)   └──────────────

I2S Philips 标准格式:
- 32 bit slot width
- 16 bit data (MSB first)
- 左声道 (WS=低)
- 采样率 = 16kHz
- BCLK = 16kHz × 32 × 2 = 1.024 MHz
```

### 6.2 红外避障 — TCRT5000 ×2

```
ESP32-S3              TCRT5000 (×2, 左右各一)
────────              ───────────────────────
GPIO14 ←────────────── OUT (左)
GPIO15 ←────────────── OUT (右)

3.3V ────→ VCC
GND ─────→ GND

输出:
  检测到障碍物 (反射) → LOW
  无障碍物             → HIGH (上拉)
```

### 6.3 红外防跌落 — ITR20001 ×2

```
ESP32-S3              ITR20001 (×2, 左右各一)
────────              ───────────────────────
GPIO16 ←────────────── OUT (左)
GPIO17 ←────────────── OUT (右)

3.3V ────→ VCC
GND ─────→ GND

输出:
  检测到桌面 (反射) → LOW (安全)
  无反射 (悬空)      → HIGH (危险!)
```

> **注意:** TCRT5000 和 ITR20001 的逻辑相反：
> - TCRT5000: LOW = 有障碍物
> - ITR20001: HIGH = 有跌落危险

## 8. 复位与启动电路

### 8.1 EN 复位电路

```
3.3V
  │

 └┬┘
  │

  │

 └┬┘
  │

### 8.2 BOOT 按钮

```
3.3V
  │
 ┌┴┐ 10kΩ (上拉)
 └┬┘
  │
  ├──→ ESP32-S3 GPIO0
  │

## 9. 设计检查清单

### 9.1 电源检查

- [ ] 所有 IC 的 VDD/VCC 引脚有去耦电容
- [ ] 去耦电容尽量靠近 IC 引脚
- [ ] 电源入口有大容量电解电容 (100μF)
- [ ] 5V 和 3.3V 走线足够宽 (≥0.5mm)
- [ ] 地平面完整，无分割
- [ ] 电池连接有保护（防反接）

### 9.2 信号检查

- [ ] I2C 上拉电阻 4.7kΩ 到 VDD
- [ ] SPI 信号线等长（可选，40MHz 不严格要求）
- [ ] 所有未用 GPIO 有明确处理（上拉/下拉/浮空）
- [ ] Strapping 引脚有正确上下拉
- [ ] 电机 PWM 走线远离模拟信号

### 9.3 ESD/EMI 检查

- [ ] USB 口有 TVS 保护
- [ ] 电机驱动有续流二极管保护（DRV8833 内置）
- [ ] 音频走线远离电机 PWM 走线
- [ ] ESP32-S3 天线区无覆铜和走线
- [ ] 扬声器走线尽量短且宽
