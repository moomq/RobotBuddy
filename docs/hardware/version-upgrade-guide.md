## ✅ 操作步骤

### 1. 确认备份存在

KiCad 自动备份位置：
- `hardware/.mcp-backups/` - 项目已有备份
- KiCad 也会在保存时创建 `.kicad_sch-bak` 文件

### 2. 安全升级流程

在 KiCad 中：

1. **点击 "确定" 或 "Save"** 继续打开文件
2. KiCad 会将文件从 10.0 格式升级到 10.0.4 格式
3. 这是**向后兼容**的升级，不会丢失数据

### 3. 升级后检查

打开文件后，检查：
- [ ] 所有符号显示正常
- [ ] 连线无丢失
- [ ] Sheet Pin 位置正确

### 4. 保存升级后的文件

- 第一次保存会更新文件格式
- 建议立即保存（Ctrl+S）
- 文件会自动更新为 10.0.4 格式

## 🔧 常见问题

### Q: 升级后文件无法在旧版本打开？

**A**: 正常。KiCad 10.0.4 保存的文件无法在 10.0.0 或更早版本打开。

**解决方法**:
- 所有团队成员升级到 10.0.4
- 或指定使用特定版本

### Q: 升级会丢失数据吗？

**A**: 不会。子版本升级（10.0 → 10.0.4）完全兼容，不会丢失任何数据。

### Q: 升级后 ERC 结果不同？

**A**: 可能。新版本可能修复了 ERC 规则或添加了新检查项。这是正常的。
