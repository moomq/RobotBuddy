## 🔧 修复悬空标签的标准流程

```
1. 打开子图
2. 按 T, E 运行 ERC 找到错误位置
3. 双击错误跳转到位置
4. 按 W 添加导线
5. 从层次标签引脚画线到元件引脚
6. 保存 (Ctrl+S)
7. 再次运行 ERC 验证
```

---

## ⚠️ 常见问题快速解决

| 问题 | 解决方法 |
|------|---------|
| 找不到标签位置 | 使用坐标定位，或 Ctrl+F 搜索标签名 |
| 标签方向错误 | 右键 → Edit → 改 Shape 属性 |
| 网络名称冲突 | 删除重复标签或重命名 |
| 引脚类型不匹配 | 检查元件引脚定义 |
| 导线连接不上 | 检查网格对齐，放大查看 |
