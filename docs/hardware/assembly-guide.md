## 2. 焊接顺序

> **原则:** 低矮元件 → 高元件 → 模块 → 连接器

### Phase 1: 被动元件 (最低)

1. **电阻** (0402)
   - R1-R6: 10kΩ (上拉/分压)
   - R7-R8: 4.7kΩ (I2C 上拉)
   - R9-R10: 100kΩ (电池分压)
   - R11: 1.2kΩ (TP4056 PROG)
   - R12-R13: 5.1kΩ (Type-C CC)

2. **电容** (0402/0805/1206)
   - C1-C15: 100nF (IC 去耦)
   - C16-C20: 10μF (IC 去耦)
   - C21-C22: 22μF (LDO 输出)
   - C23-C24: 100μF (电源去耦)

3. **电感**
   - L1: 22μH (MT3608 升压)

4. **TVS / 保险丝**
   - TVS1: USB ESD 保护
   - F1: 3A 自恢复 (5V)
   - F2: 2A 自恢复 (3.3V)

### Phase 2: IC (中等高度)

5. **电源 IC**
   - U2: TP4056 (SOP-8)
   - U3: MT3608 (SOT-23-5) — 注意: 如果使用模块则跳过
   - U4: AMS1117-3.3 (SOT-223)

6. **连接器**
   - J1: Type-C 母座 (SMD)
   - J2: FPC 连接器 8Pin (LCD)
   - J3-J4: PH2.0 2Pin (电机)
   - J5: PH2.0 2Pin (扬声器)
   - J6: 排针 (传感器扩展)

### Phase 3: 模块 (最高)

7. **ESP32-S3 模组** (焊接或排针)
   - 建议先焊接排针座，用杜邦线连接
   - 或直接焊接模组到底板

8. **传感器模块** (排针连接)
   - MPU6050 模块
   - TCRT5000 模块 ×2
   - ITR20001 模块 ×2

9. **音频模块** (排针连接)
   - INMP441 模块
   - MAX98357A 模块

10. **电机驱动** (排针连接)
    - DRV8833 模块

## 3. 组装步骤

### Step 1: PCB 焊接

```
1. 检查 PCB 无短路 (万用表通断档)
2. 按照焊接顺序焊接所有被动元件
3. 焊接 IC 和连接器
4. 清洗助焊剂残留
5. 目视检查所有焊点
```

### Step 2: 电源验证

```
⚠️ 上电前检查!

1. 万用表测量 3.3V 和 GND 之间电阻 (>1kΩ)
2. 万用表测量 5V 和 GND 之间电阻 (>500Ω)
3. 插入 18650 电池 (注意正负极!)
4. 测量 5V 轨 → 应为 ~5.0V
5. 测量 3.3V 轨 → 应为 ~3.3V
6. 拔出电池
7. 连接 Type-C USB
8. 测量充电状态 → CHRG 应为低电平
```

### Step 3: ESP32-S3 模组安装

```
1. 将 ESP32-S3 模组插入排针座
   (注意方向! USB 口朝向 Type-C 接口方向)
2. 插入 Type-C 数据线连接电脑
3. 确认电脑识别到串口 (COM 端口号)
4. 测试进入 Download 模式:
   按住 BOOT 按钮 → 按 RESET → 松开 BOOT
```

### Step 4: LCD 屏幕安装

```
1. 将 FPC 排线插入 LCD 连接器
   (注意方向! 金手指朝下)
2. 锁紧 FPC 连接器卡扣
3. 暂时不安装外壳
```

### Step 5: 传感器安装

```
1. MPU6050: 安装在 PCB 中央偏上，水平放置
2. TCRT5000 ×2: 安装在前方，朝前发射
3. ITR20001 ×2: 安装在底部两侧，朝下发射
4. 连接杜邦线到对应排针
```

### Step 6: 音频安装

```
1. INMP441: 安装在顶部，麦克风孔朝前
2. MAX98357A: 安装在底部，靠近扬声器
3. 扬声器: 用热熔胶固定在外壳底部
4. 连接杜邦线
```

### Step 7: 电机安装

```
1. N20 电机 ×2: 安装在底盘两侧
2. 连接电机线到 DRV8833 模块
3. 安装轮胎到电机轴
4. 确保电机方向一致 (同向前进)
```

### Step 8: 电池安装

```
1. 将 18650 电池放入电池座
   (注意正负极方向!)
2. 电池应位于底盘底部 (降低重心)
3. 用扎带或热熔胶固定
```

### Step 9: 外壳组装

```
1. 将 PCB 安装到底盘盖板上 (M2 螺丝)
2. 将 LCD 屏幕安装到屏幕框架
3. 将屏幕框架安装到外壳上半部分
4. 连接所有排线
5. 将上半部分和下半部分合拢
6. 用 M3 螺丝固定
```

## 4. 初次烧录

### 4.1 进入烧录模式

```bash
# 方法 1: 按键
1. 按住 BOOT 按钮
2. 按 RESET 按钮
3. 松开 BOOT 按钮

# 方法 2: 命令行
esptool.py --chip esp32s3 --port COMX erase_flash
```

### 4.2 烧录固件

```bash
# 设置 ESP-IDF 环境
. $HOME/esp/v5.1/export.sh  # Linux/macOS
# 或
%USERPROFILE%\esp\v5.1\export.bat  # Windows

# 编译并烧录
cd firmware
idf.py build
idf.py -p COMX flash monitor
```

### 4.3 验证清单

- [ ] 串口输出: `=== Board Initialization Start ===`
- [ ] SPI 初始化成功: `SPI bus initialized`
- [ ] I2C 初始化成功: `I2C bus initialized at 400000 Hz`
- [ ] LCD 点亮: 背光亮，显示初始化
- [ ] 麦克风: I2S 采集数据非零
- [ ] 扬声器: 播放测试音
- [ ] 电机: 两个电机正反转
- [ ] MPU6050: 读取 WHO_AM_I = 0x68
- [ ] 红外传感器: 遮挡时输出变化
- [ ] 电池电压: ADC 读数合理
- [ ] WiFi: 可以连接到 AP
- [ ] OTA: 可以从服务器下载固件

## 5. 常见问题

### 5.1 焊接问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 短路 | 焊锡桥连 | 用吸锡器清除，重新焊接 |
| 虚焊 | 焊锡量不足 | 补焊 |
| 元件方向错 | 反接 | 检查极性标记，重新焊接 |
| ESP32 不启动 | 电源问题 | 检查 3.3V 是否正常 |

### 5.2 硬件问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| LCD 不亮 | 背光未开或接线错 | 检查 BL 引脚和接线 |
| 无声音 | MAX98357A 接线错 | 检查 I2S 和供电 |
| 电机不转 | DRV8833 未供电 | 检查 5V 和 nSLEEP |
| I2C 设备不响应 | 上拉电阻缺失 | 检查 SDA/SCL 上拉 |
| WiFi 连不上 | 天线区有金属 | 确保 ESP32 天线下方无覆铜 |
