## 4. 开发路线图

### 4.1 V1.0 MVP — 基础功能（当前阶段）

**目标:** "先跑起来，能聊代码"

**核心 Commands/Skills:**

| 类别 | 需要的文件 | 优先级 |
|------|-----------|--------|
| 功能开发 | `/feature`, `requirement`, `architecture`, `coding` | P0 |
| 硬件调通 | `/hardware-bringup`, `hardware-driver`, `bsp`, `/pin-check` | P0 |
| 固件开发 | `/firmware`, `freertos-system` | P0 |
| WiFi 配网 | `wifi-setup` | P0 |
| 表情显示 | `display-engine`, `lvgl-ui` | P0 |
| 音频管道 | `audio-pipeline` | P0 |
| 运动控制 | `motion-control` | P0 |
| 传感器 | `sensor-fusion`, `calibration`, `/calibrate` | P0 |
| 电源管理 | `power-management` | P0 |
| 行为系统 | `behavior-system` | P0 |
| AI 对话 | `ai-dialog` | P0 |
| 云端通信 | `cloud-communication`, `ota` | P0 |
| 编译烧录 | `/flash`, `/scaffold` | P0 |
| 测试验证 | `/test`, `testing` | P0 |
| 代码审查 | `/review`, `review` | P0 |
| 调试诊断 | `/debug`, `/log` | P0 |
| 清理依赖 | `/clean`, `/deps` | P0 |
| 引脚管理 | `/pin-check` | P0 |
| 文档 | `document` | P0 |

**MVP 开发顺序建议:**

```
第1周: BSP → WiFi → 显示(基础表情)
       /hardware-bringup → bsp → wifi-setup → display-engine

第2周: 音频 → AI对话 → 行为系统
       audio-pipeline → ai-dialog → behavior-system

第3周: 传感器 → 运动 → 电源管理
       sensor-fusion + calibration → motion-control → power-management

第4周: 集成联调 → 测试 → 发布
       /feature (集成) → /test → /review → /release → /deploy
```
