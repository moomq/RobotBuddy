① Command 模板（精简版）
feature.md

```
# /feature

## Purpose

实现一个完整功能。

## Workflow

1. 阅读需求
2. 调用 requirements skill
3. 调用 architecture skill
4. 调用 coding skill
5. 调用 unittest skill
6. 调用 review skill
7. 输出最终结果

## Output

- 需求分析
- 技术方案
- 实现代码
- 单元测试
- Review结果
```
